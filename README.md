# Machine Learning-with-Knime-source-rock-shahai.
* Objective and dataset (84 samples, Shahai Formation).   
* How to open: in KNIME 5.9.0, go to File → Import KNIME Workflow…, select the .knwf file, and click Finish.   
* Final result: Random Forest with 100 trees, a depth of 3, and a minimum of 2 samples per node; accuracy 0.964, Kappa 0.923.   
* Reproducibility: 5-fold stratified cross-validation with a random seed of 12345.
